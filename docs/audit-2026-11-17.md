# FinalFolio Audit — 2026-11-17

Strict product/engineering review across the storefront, editor, account, admin,
public reader, mobile and desktop breakpoints, plus the photo → layout → text →
export/share flow.

## Method

- Static review of `src/`, `server/`, `deploy/`, `scripts/`, `tests/` and docs.
- `tsc --noEmit`, `npm run build`, `npm run validate:mvp`, Playwright (16 specs).
- Runtime sweep of `/`, `/editor`, `/account`, `/admin`, `/terms`, `/privacy`,
  `/project/:shareId`, and the 404 route: console errors, failed requests,
  missing alt text, unnamed buttons, unlabeled inputs, `h1` count.
- Responsive overflow checks at 360 / 390 / 768 / 1024 / 1440.
- Hover audit of every visible button for displacement and short-label wrapping.
- `npm audit` (runtime dependencies) and dependency review.
- Export/share parity: exported PDF parsed with `pdf-lib` (page count + A4 size)
  and the public reader asserted to render pages without runtime errors.

## Issues found and fixed

### Interaction / UX

- Layout picker hover blurred the content and overlaid actions; replaced with
  click-to-select plus three explicit actions (insert above / replace / insert
  below). Hover only shows the description tooltip.
- The empty-frame “上传照片” CTA wrapped and jumped sideways on hover because the
  shared button rule forced wrapping and the hover transform replaced the
  centering transform. Centred with auto margins, forced `nowrap`, neutralised
  hover transforms, and audited every button for the same pattern.
- Buttons across the editor defaulted to `white-space: normal`; now `nowrap`
  with explicit opt-in for long status copy.
- Sequence chips: aligned page number/layout/colour dot in one row, actions on
  their own row, smaller icons matching the colour dot, trash icon for delete.
- Photos panel had an oversized duplicate heading; replaced with a compact label
  and on-demand URL import.
- Editor sidebars now share one 32 px header row, 14 px padding and 12 px gap
  rhythm; the project title stays visible while secondary project info collapses.
- Empty frames expose a direct upload action that assigns the uploaded photo to
  that frame.

### Localisation

- Custom layout names and frame labels are localised on create/load/clone
  (编辑分栏, 主图, 细节 A, 插图 A, 缎带随笔, 图注栏, 小样网格).
- Remaining dynamic copy translated: upload/restore toasts, template and theme
  messages, page limits, selected frame labels, upload progress, admin trend
  dates/hours, error boundary, editor-topbar menu.
- Structural labels (page numbers, frame hints, endpapers, range labels) localised.

### Reliability / security

- Fixed the public reader regression where detached turn.js roots lacked
  `LocaleProvider` and blanked the book; `useT()` now falls back safely and the
  root is wrapped.
- Deduped jQuery for turn.js to 3.7.1; `npm audit` now reports 0 vulnerabilities.
- Added an admin console smoke test and a direct frame-upload test.
- Export test now verifies PDF page count and A4 page geometry.
- URL import keeps SSRF guards, redirect re-validation, size caps and magic-byte
  validation; session cookies remain HttpOnly/SameSite=Lax/Secure in production.

### Docs / config

- README stack/deploy instructions corrected (Express + Caddy, not static Nginx),
  rsync command fixed, environment table added.
- `.env.example` and compose now document the upload/page/asset/login limit
  variables.

## Evidence

- `npm run validate:mvp` passes.
- Playwright: 16/16 pass (auth, API security, save race, editor flow, editor UX,

- Runtime sweep: 0 console errors, 0 failed requests, 0 missing alt text,

## Residual risks / next steps

1. Rotate the SMTP password if it was ever exposed via `docker inspect` or an old
   commit, and run a restore drill from `/opt/finalfolio/backups`.
2. URL import resolves DNS and then fetches; a determined attacker could attempt
   DNS rebinding. Pinning the resolved IP for the actual request would close this
   residual TOCTOU window.
3. `EditorPage.tsx` and the editor state hooks remain large; splitting the layout
   picker, project info and stage editing into focused modules would reduce
   regression risk.
4. There is no lint/format gate; adding ESLint + Prettier to CI would catch the
   class of CSS/JSX issues found manually here.
5. The WenKai display subset covers GB2312 level-1; rare characters in user copy
   fall back to the system font.
6. Existing user-authored content (old drafts, saved templates, project names)
   keeps its original language; only system copy and newly created pages are
   localised.

## Follow-up — unified layout library (same day)

### What changed

- Custom layout presets moved out of the custom builder and into the main
  **Page layout** grid. They use the same A4 `LayoutThumbnail` cards as the
  built-in layouts.
- The first four built-ins plus two saved layouts stay visible; the remaining
  built-ins and saved layouts collapse behind **More layouts (n)**.
- Every saved layout is now renameable, savable, duplicable and deletable. The
  old fixed “Contact grid / 小样网格” label is now “Four-up notes / 四格图注” and
  follows the same edit/delete rules as any other layout.
- The layout library persists in `localStorage`
  (`finalfolio-custom-layouts-v1`). If storage is blocked, saving still works
  for the session and the toast says so.
- Built-in scaffolds keep canonical English names internally, so switching the
  interface language re-localises unchanged names instead of freezing them.
- Switching away from a layout with unsaved edits now asks for confirmation.
- The custom builder shows an explicit **Layout map** disclosure instead of a
  hover/focus preview. This removes a real click-loss bug: focusing a builder
  button used to insert the inline preview above it, moving the button between
  mousedown and mouseup so the click never fired.
- UI radii reduced: site/editor surfaces 26→20, panels 16→12, cards 12→8,
  controls 5→4, overlays 18→14 (plus the corresponding viewer/mobile surfaces).

### Verification

- `tsc`, `npm run build`, `npm run validate:mvp`.
- Playwright: 22/22 (added saved-layout grid, new-layout visibility, rename
  persistence, delete, insert-link retention and unsaved-edit confirmation
  coverage).
- Runtime sweep: 0 console errors, 0 failed requests, 0 missing alt text,
  0 unnamed buttons, 0 unlabeled inputs, one `h1` per route.
- 360/390/768/1024: no horizontal overflow.
- Manual storage check: saving an unchanged built-in stores its canonical
  English name; the Chinese UI renders it localised after reload.

### Residual risk

- The layout library is browser-local, not account-synced. A shared browser
  shows the same library to every account on that device; the UI states this
  explicitly. Server-side sync would be the next step if cross-device reuse is
  required.

## Follow-up — AI arrangement
